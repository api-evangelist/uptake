The Uptake Accounts application has grown, in the past year, from being a central location for users to log on to the Uptake Platform to a fully featured tool for managing users, roles, and tenants. As one of the first web applications to join the Uptake Platform, Accounts often gets to be an early adopter of new design components , technologies and practices. Accounts has always had a solid JUnit test suite for its Java back end and Jest test suite for its Vue.js front end.
